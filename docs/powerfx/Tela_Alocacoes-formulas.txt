# Tela_Alocacoes (Desktop)
#
# Designa projeto (Campanhas) + instalacao (Subestacoes) a um slot.
# Front: Projeto. Lista SP: Campanhas. Uma linha Alocacoes = Login + CodInventario + CodSE.
# Mobile filtra por esta lista: inventariante só vê o designado; escritório vê tudo.
# Spec: docs/powerfx/mobile-filtro-alocacao.txt
# Locale PT-BR: ; nos argumentos | ;; nas instrucoes
# Mockup: docs/screens/mockup-usuarios-alocacoes.html · docs/screens/mockup-usuarios-alocacoes-estados.html
# PNG: docs/screens/usuarios-alocacoes.png · docs/screens/usuarios-alocacoes-estados.png
#      usuarios-alocacoes-adicionar.png · designada.png · ocupada.png · vazia.png
#      docs/screens/usuarios-galeria-usado-por.png
# Entra com varUsrSel da Tela_Usuarios.

## Recorte

# Escritorio escolhe o slot, depois o projeto, depois a SE. Adicionar grava.
# Uma SE so pode estar em um slot ativo (um editor por SE).
# Nao carrega Inventario (itens). Usa colCampanhas + colSubestacoes do OnStart.

## A. SharePoint — lista `Alocacoes` (uma vez)

Site AssetPro. Nova lista, nome **Alocacoes** (sem acento).

| Coluna | Tipo | Exemplo |
|--------|------|---------|
| Title | texto (obrigatorio) | `Inventariante01-SE-001` |
| Login | texto | `Inventariante01` |
| CodUsuario | texto | `USR-001` |
| UsadoPor | texto | `Ricardo` |
| CodInventario | texto | `INV-012` |
| NomeInventario | texto | `Neoenergia PE` |
| CodSE | texto | `SE-001` |
| NomeSE | texto | `Sub. Est. Recife I` |
| Ativo | texto | `Sim` |

Ativo e texto `Sim` / `Nao`, igual o resto.

Desktop e Mobile: Dados → adicionar a lista **Alocacoes**.

### 16. btnAloAdd → OnSelect

Apaga o que estiver la. Cola:

```
If(
    IsBlank(varUsrSel);
    With(
        {_: true};
        Set(varToastMsg; "Volte e escolha um slot.");;
        Set(varToastTipo; "AVISO");;
        Set(varToastOn; false);;
        Set(varToastOn; true)
    );
    Patch(
        Alocacoes;
        Defaults(Alocacoes);
        {
            Title: varUsrSel.Login & "-" & ThisItem.CodSE;
            Login: varUsrSel.Login;
            CodUsuario: varUsrSel.CodUsuario;
            UsadoPor: varUsrSel.UsadoPor;
            CodInventario: ThisItem.CodInventario;
            NomeInventario: varAloCamp.NomeInventario;
            CodSE: ThisItem.CodSE;
            NomeSE: ThisItem.NomeSE;
            Ativo: "Sim"
        }
    );;
    Refresh(Alocacoes);;
    Set(varToastMsg; "Instalação designada.");;
    Set(varToastTipo; "OK");;
    Set(varToastOn; false);;
    Set(varToastOn; true)
)
```
