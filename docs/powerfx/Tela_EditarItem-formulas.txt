## OnVisible — início (varRegistroAtual + desfecho + TUC)

Colar no **início** do `OnVisible` da `Tela_EditarItem` — **antes** de `varAtrA1` e de qualquer `Coalesce(varRegistroAtual…)`.

**Pré-requisitos** (vêm da tela anterior, ex. `Tela_ItensVisita`):
- `varItemFoto` — registro da base contábil (`colInventarioBase`) ou da sobra (`colCampoOffline`)
- `varCodRef` — `CodAsset` do item (também na sobra já enviada)
- `varCodSE` — subestação
- `varModo` — `"EDITAR"` (base) ou `"NOVO"` (sobra física). **Não** recalcular com `IsBlank(varCodRef)`.
- `varCodTemp` — **não usar**. Chave é só `varCodRef` / `CodAsset`.

No **início** do `OnVisible`, **não** gerar GUID novo. A sobra já nasce com `varCodRef` no `btnAddItem`.

```powerfx
Set(
    varRegistroAtual;
    LookUp(
        colCampoOffline;
        CodInventario = gblInventarioSelecionado.CodInventario
        && !IsBlank(varCodRef)
        && CodAsset = varCodRef
    )
);;

Set(
    varModo;
    If(
        Coalesce(varModo; "") = "NOVO"
        || StartsWith(Coalesce(Text(varCodRef); ""); "SOBRA-")
        || Coalesce(varRegistroAtual.SobraTipo; "") = "SOBRA_FISICA"
        || Coalesce(varRegistroAtual.Sobra; "") = "SOBRA_FISICA"
        || Coalesce(varRegistroAtual.TipoRegistro; "") = "SOBRA_FISICA";
        "NOVO";
        Coalesce(varModo; If(IsBlank(varCodRef); "NOVO"; "EDITAR"))
    )
);;
Set(
    varDesfecho;
    Coalesce(
        varRegistroAtual.TipoRegistro;
        If(varModo = "NOVO"; "SOBRA_FISICA"; "CONFIRMACAO")
    )
);;
Set(varTUCSelecionado; Coalesce(varRegistroAtual.CodTUC; varItemFoto.CodTUC));;

// … em seguida: varAtrA1…A6, varA1…A6, vars técnicas, Resets …
```

**O que é `varRegistroAtual`:** rascunho já salvo offline nesta visita (`colCampoOffline`). Se o técnico nunca clicou Salvar neste item, o `LookUp` não acha nada → fica `Blank()` → o `Coalesce` usa `varItemFoto` (base SAP).

**Não** criar no `App.OnStart` — só neste `OnVisible`.

            ""
        );
        IdUC: Coalesce(Trim(varIdUC); varRegistroAtual.IdUC; varItemFoto.IdUC; "");
        AtributoA1: Coalesce(
            cmbA1.Selected.CodTabela;

            varItemFoto.AtributoA1;
            varItemFoto.A1

        AtributoA4: Coalesce(IfError(cmbA4.Selected.CodTabela; Blank()); varA4);
        AtributoA5: Coalesce(IfError(cmbA5.Selected.CodTabela; Blank()); varA5);
        AtributoA6: Coalesce(IfError(cmbA6.Selected.CodTabela; Blank()); varA6);
        ValorA2: Upper(If(Upper(Trim(varTipoA2)) = "FAIXA"; Coalesce(inpA2Faixa.Text; varValorA2; ""); If(Upper(Trim(varTipoA2)) = "LIVRE"; Coalesce(inpA2Livre.Text; varValorA2; ""); "")));
        ValorA3: Upper(If(Upper(Trim(varTipoA3)) = "FAIXA"; Coalesce(inpA3Faixa.Text; varValorA3; ""); If(Upper(Trim(varTipoA3)) = "LIVRE"; Coalesce(inpA3Livre.Text; varValorA3; ""); "")));

        ValorA5: Upper(If(Upper(Trim(varTipoA5)) = "FAIXA"; Coalesce(inpA5Faixa.Text; varValorA5; ""); If(Upper(Trim(varTipoA5)) = "LIVRE"; Coalesce(inpA5Livre.Text; varValorA5; ""); "")));
        ValorA6: Upper(If(Upper(Trim(varTipoA6)) = "FAIXA"; Coalesce(inpA6Faixa.Text; varValorA6; ""); If(Upper(Trim(varTipoA6)) = "LIVRE"; Coalesce(inpA6Livre.Text; varValorA6; ""); "")));
        DescricaoBem: With(
            {
                prefixoImob:
                    If(
                        varModo = "NOVO";
                        "";
                        Coalesce(
                            Trim(
                                Coalesce(
                                    Text(varItemFoto.Imobilizado);
                                    Text(varRegistroAtual.Imobilizado);
                                    ""
                                )
                            );
                            "—"
                        ) & " · "
                    );
                prefixoTuc: Trim(

                        IsBlank(Coalesce(cmbA1.Selected.CodTabela; varA1));

                            texto0
                        )
                };
                If(
                    StartsWith(texto1; prefixoTuc);
                    Mid(texto1; Len(prefixoTuc) + 1; Len(texto1));

                )

            )

        NumSerie: Upper(Coalesce(inpNumSerie.Text; varNumSerie; ""));
        CodOperacao: Upper(Coalesce(inpCodOperacao.Text; varCodOperacao; ""));

        SobraTipo: If(varModo = "NOVO"; "SOBRA_FISICA"; "");
        Sobra: If(
            varModo = "NOVO";
            "SOBRA_FISICA";
            varDesfecho = "NAO_ENCONTRADO";
            "SOBRA_CONTABIL";
            ""
        );
        Sincronizada: false;
        IdInventario: Coalesce(varRegistroAtual.IdInventario; varItemFoto.ID; varItemFoto.IdInventario; 0)

## BUG 2026-08-22 — DescricaoBem repetida em todos os registros

Sintoma: colCampoOffline com 3 registros de CodTUC diferentes (570; 210; 160)

varDescSelecionada e global e sobrevive a navegacao. O Coalesce le a propria
variavel primeiro, entao o valor do PRIMEIRO item aberto nunca mais e trocado.
O Salvar grava DescricaoBem: varDescSelecionada -> contamina todos os itens.

    Set(
        varDescSelecionada;
        Coalesce(varRegistroAtual.DescricaoBem; varItemFoto.DescricaoBem; "")
    );;
E remover a linha antiga que ficava antes do LookUp.

Regra geral: nenhuma variavel global de item pode aparecer dentro do proprio
Coalesce no OnVisible. O mesmo vale para varTUCSelecionado; varUnidadeItem; varA1..A6.
