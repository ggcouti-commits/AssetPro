## Troca do Notify

**So no app Desktop.** No mobile o `Notify` fica.

No lugar de:

```
Notify("Planilha gerada"; NotificationType.Success)
```

Cola:

```
Set(varToastMsg; "Planilha gerada");;
Set(varToastTipo; "OK");;
Set(varToastOn; false);;
Set(varToastOn; true)
```

| Notify antigo | varToastTipo |
|---------------|--------------|
| NotificationType.Success | `"OK"` |
| NotificationType.Error | `"ERRO"` |
| NotificationType.Warning | `"AVISO"` |
| NotificationType.Information | `"AVISO"` |

Popup de importar / excluir **nao muda** — continua overlay. Toast so substitui o banner nativo.

---

## O que nao fazer

- Nao deixar Notify e toast no mesmo clique.
- Nao montar cmpToast / varToast no app mobile.
- Nao usar Cor.Warning / amarelo.
- Nao colocar o toast dentro do cmpMenuV1 (componente Mundo Power).
- Nao usar mask / fundo escurecido — toast nao trava clique.
- Nao escrever Cor. dentro do componente. Cor so na instancia da tela.
