# Schema — lista Inventario (dummy das colecoes)
#
# Locale PT-BR: ; nos argumentos | ;; nas instrucoes
# Fonte da lista: importacao + exportacao + baixar.
# App.OnStart (Mobile): ClearCollect com ESTE dummy, Clear, LoadData,
# depois o bloco "forcar" (Collect dummy + Set Last + Remove + Blank).
# Desktop: depois do Clear(colInventarioBase), o mesmo forcar (sem LoadData).
#
# Nao entra: Author, anexos, @odata. Title entra (SP obriga).
# colCampoOffline soma campos da FILA (nao existem na lista).

# Numero = 0. Texto = "". Sim/Nao = "".

## Conferencia

| Colecao | Onde | Dummy |
|---------|------|--------|
| `colCampoOffline` | Mobile OnStart | B (lista + fila) |
| `colInventarioBase` | Mobile OnStart + forcar pos-LoadData | A |
| `colInventarioBase` | Desktop OnStart (colecao vazia) | A |
| `colItensSEConsulta` | Tela_ItensConsulta.OnVisible | A |

`varRegistroAtual` = tipo de `colCampoOffline`. `varItemFoto` = tipo de `colInventarioBase`. Play no app depois de colar.
