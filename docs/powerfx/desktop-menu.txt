# Desktop — cmpMenuV1 (Studio 2026-09-04)
# Fonte do menu: App.Formulas → TabelaMenu.
# Front: item campanhas mostra "Projetos". Key e Navigate nao mudam.
# Cores: CoresLight / CoresDark / TextCores* iguais ao mobile.
# Locale PT-BR no Studio: ; nos argumentos | ;; entre instrucoes.

## Regra de perfil

| `varPerfil` | Menu | StartScreen (apos OnStart) |
|-------------|------|----------------------------|
| `ESCRITORIO` | `TabelaMenu` inteira | `Tela_Campanhas` |
| `INVENTARIANTE` | **So** item `Key = "inventarios"` | `Tela_Inventarios` |

Desktop e so escritorio: `varPerfil = "ESCRITORIO"` no OnStart (conta M365 unica). Campo autentica na `Tela_Login` do Mobile (lista `Inventariantes`). CRUD dos slots: `Tela_Usuarios`. Ver `AppDesktop-OnStart.txt`.

Mockups: inventariante so ve **Inventarios** — `docs/screens/mockup-inventario-desktop.png`, `mockup-inventario-fluxo.html`.

---

## Passo a passo — Studio

### 1. `App` → `OnStart`

Perfil fica `ESCRITORIO` em `docs/powerfx/AppDesktop-OnStart.txt`. Sem redirect para Inventarios.

### 2. `cmpMenuV1_1` (em cada tela que usa o menu) → propriedade **DataSource**

Apaga `TabelaMenu`. Cola:

```
If(
    varPerfil = "INVENTARIANTE";
    Filter(TabelaMenu; Key = "inventarios");
    TabelaMenu
)
```

**Resultado:** inventariante ve um unico item no menu lateral.

### 3. cmpMenuV1_1 → OnSelect

Incluir (ou conferir) o case **inventarios** — coleta de dados, **nao** consulta Subestacoes:

```
Switch(
    varMenuKey;
    "home"; Navigate(Tela_Home; ScreenTransition.None);
    "exportar"; Navigate(Tela_Exportar; ScreenTransition.None);
    "campanhas"; Navigate(Tela_Campanhas; ScreenTransition.None);
    "conferencia"; Navigate(Tela_Conferência; ScreenTransition.None);
    "inventarios"; Navigate(Tela_Inventarios; ScreenTransition.None);
    "cadastros"; Navigate(Tela_Cadastros; ScreenTransition.None);
    "concessionarias"; Navigate(Tela_Cadastros; ScreenTransition.None);
    "usuarios"; Navigate(Tela_Usuarios; ScreenTransition.None)
)
```

### 4. (Opcional) Subtitulo do usuario no menu

Se o componente expuser rotulo de perfil, usar algo como:

```
If(varPerfil = "INVENTARIANTE"; "inventariante"; "escritório")
```
