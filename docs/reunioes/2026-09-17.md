# Reunião 17.09.2026 — decisões (campo + escritório)

> Fenômeno. Valer no app. Studio: `docs/powerfx/pauta-2026-09-17-studio.md`.

## O que ficou fechado

1. **Reserva no mobile.** Técnico marca o equipamento como reserva na ficha (`Tela_EditarItem`). Campo já existe: `Inventario.Reserva` (`SIM` / `NÃO`). Não é TI 98-RES.
2. **Mobile só vê o designado.** Slot vê só projeto + SE que está em `Alocacoes` (Login + Ativo = Sim). Não baixa / não lista o resto.
3. **Imobilizado na frente da TUC** no card da galeria de itens (mobile). Ordem: Imobilizado · TUC.A1 · descrição.
4. **Tirar Confirmar / Não encontrado da galeria.** Desfecho só na `Tela_EditarItem` (lápis → ficha). `btnConfirmarBase` e `btnNaoEncontradoBase` somem.
5. **Bug: Salvar confirma todos.** `LookUp` da galeria usa `CodAsset = CodAsset` (sempre verdade). Cada card pega o mesmo rascunho. Corrigir com `As itemBase`.
6. **Descrição na galeria não atualiza.** Salvar grava em `colCampoOffline` / SharePoint; o título lê `colInventarioBase`. Desktop (consulta SP) já mostra. Mobile tem que ler o rascunho e dar `UpdateIf` na base local.
7. **Slot no desktop → mobile reloga.** Qualquer operação no slot (salvar, designar, tirar SE, excluir) incrementa `SessaoVersao`. Timer do mobile já compara. Sem rede: não chuta.
8. **Enviar SE muda o status do projeto.** `Campanhas.Status` não pode ficar `Pendente` depois do envio. Primeira SE enviada → `Em andamento`. Todas as SEs `Finalizada` → `Concluído`.
9. **Não encontrado → quantidade encontrada = 0** sempre. Base (`Quantidade`) não zera. Campo (`QuantidadeCampo`) = 0. Input trava em 0.
10. **Designar várias SEs num clique.** Galeria com seleção + um botão. Uma linha `Alocacoes` por SE (um editor por SE).
11. **Busca no mobile.** Campo na `Tela_ItensVisita` (descrição, TUC, imobilizado, CodAsset).
