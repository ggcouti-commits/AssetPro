## Decisões

### App — fluxo por tipo

- **Admin / escritório:** na entrada, escolher o ramo (Elétrica × Gás canalizado × …).
- **Inventariante em campo:** **não** escolhe o tipo. Vê só inventários alocados; a listagem já vem no formato certo.
- Ao abrir o inventário: mesma lógica de hoje (locais / “SE” vs rede). O que muda de verdade é a **ficha do item**.
- Preferência do Fenômeno na reunião: **reutilizar tela** quando der (menos tela = melhor performance em campo). Decisão de implementação (tela nova vs mesma com Visible) — ver planejamento.

### Base gás — campos

| Campo | Como preenche |
|-------|----------------|
| Índice / ordem | Coluna de ordem (como elétrica) |
| Número (deles / nosso) | Vem na base ou gera |
| Município | **Lista** (por empresa; sobe no import) |
| Código OS / código do local | Aberto se criar local; se veio na base, mantém |
| Nome / descrição do lugar | Aberto (não dá lista de milhões de lugares) |
| Segmento | **Lista**: industrial, comercial, residencial, automotivo, geração, infraestrutura… |
| Descrição resumida | **Lista** (evita “válvula block” / “válvula de bloqueio”) |
| Descrição técnica complementar | **Aberto**, opcional — escritório concatena depois com diâmetro/classe |
| Quantidade | Número |
| Unidade de medida | **Lista** (unidade, conjunto, m, m²…) |
| Elegível / Reserva | **Sim/Não** |
| Fabricante / Modelo / Nº série / Ano | Aberto |
| Diâmetro | **Lista** — polegada **e** milímetro (valores fechados na reunião; dá para ampliar depois) |
| Classe de pressão | **Lista** (100, 150, 300, 600, 1000…) — vale para todas as empresas |
| Tramo | **Lista** simples / duplo / triplo — todas as empresas |
| Tag | Às vezes vem; às vezes cria em campo |
| Plaqueta de patrimônio | Aberto |
| Coordenada | Coleta em campo |
| Observação | Aberto |

**Listas globais de gás** (não mudam de empresa): diâmetro, classe de pressão, tipo de tramo, UM, elegível/reserva.  
**Listas por empresa:** município, segmento, descrição resumida, **códigos TUC** (nome da UC igual; **código muda** — Comgás 31 ≠ outra). Precisa chave empresa ↔ código.

### Criar local em campo

- Inventariante pode **criar local** (posto / estação) se não estiver na lista — mesmo padrão do botão criar SE (caso Bahia / locais sem base).
- Precisa **sinal** (pasta de foto + Patch). Sem sinal → não cria no app; evita “fiz no caderno”.
- Rede: André completa com a base deles; criar local **não** é o foco de Rede.

### Duplicar item

- Botão **Duplicar** (não só “novo item”): abre a ficha já com município / TUC / local / campos do local preenchidos.
- **Não** copia fabricante, modelo, série (evita repetir número errado).
- Vale para gás **e** para SE elétrica (muitos itens no mesmo local).
