## Decisões do André (valer no app)

1. **Centro modular é do equipamento.** Cada item pode ter um CM diferente (0–9). Dropdown, sem digitação livre. **TI é do local** (áudio 11.09) — não misturar.
2. **Arranjo físico é da subestação.** Barra simples/dupla/etc. — custo de investimento da SE. Não vai no card do item.
3. **Local de instalação é da subestação.** Onde a SE está (distribuição / transmissão / RBSE / RBNI). Distribuição = **sempre 0 (RD)**.
4. **UI do CM:** código + nome curto (`0 — Infraestrutura geral`, `2 — Entrada de linha`). **Sem** o texto de composição do MCPSE.
5. **UI do arranjo:** código + sigla (`1 — BS`, `2 — BD`, `3 — BDDD`, `4 — BPT`, `5 — DJM`). Sem o texto longo.
6. **UI do local:** código + sigla (`0 — RD`, `1 — DIT-RPC`, `2 — RBSE`, `3 — RBNI`, `4 — DIT-RCDM`).
7. Técnico em campo costuma **não** preencher CM / arranjo / local (André completa depois). Mesmo assim entra no modelo completo, só que **escolhendo na tabela**.
8. **Bem de projeto** só no **final** da ficha. O resto ele disse que já está.
