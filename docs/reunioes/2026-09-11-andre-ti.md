## O que o André fechou

1. **TI = tipo de instalação** (tipologia do **local**). Vale para qualquer instalação elétrica — não só subestação: quadro de energia, medidores, rede, usina, administrativo, telecom, etc.
2. Na base de avaliação existe **banco de preço referencial por instalação**. Filtrar pela TI é como recortar o universo: só SE, só medição, só rede, só usina.
3. Exemplos que ele citou (não é catálogo completo):
   - Subestação: **93**, **96**
   - Rede de distribuição aérea rural e urbana: **40** e **41**
   - Usina: **10**
   - Medidores / administrativo / telecom: cada um tem o próprio código
4. **Na subestação a TI segue a maior tensão.** Entra 138 kV e sai 13 kV → a instalação é 138. Todos os ativos daquele local levam **o mesmo número de TI**.
5. **TI ≠ centro modular.** TI é do local (igual para todos os bens dali). CM é do equipamento (trafo, entrada de linha, saída de alimentador…).
6. Tudo na elétrica é **codificado**. Chave de critério: **TI + CM + TUC + atributos A1–A6**. Com isso o casamento com preço (e com a cesta de índices) não usa descrição em texto.
7. As bases que o **Tomazelli** gera (ANEEL) já vêm nessa lógica: mapa de códigos, não texto livre.
8. Na avaliação tarifária há ainda **cesta de índices por equipamento** (não só IPCA; também IGP-M e índice específico do material), derivada dessa mesma chave, para atualizar preço-referência (ex.: setembro → dezembro/janeiro).
